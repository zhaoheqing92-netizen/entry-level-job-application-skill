# 履约后上手说明：独立 Agent 离线验证

日期：2026-11-09。使用新上下文 Agent，只提供当前 SKILL.md、其按需引用与[原始三轮场景](../tests/scenarios/onboarding.md)。没有提供预期答案、改动说明或历史结论。资料和企业均为虚构，场景中没有可访问的 guide.html。

## 观察结果

| 检查点 | 实际表现 |
|---|---|
| 首次领取后说明 | 说明能力、最少资料、三条可复制指令、教程、控制方式及下一步 |
| 安装状态 | 只确认读到技能，明确无法确认本机安装和浏览器连接 |
| 教程未交付 | 给公开教程说明入口，没有虚构本地 guide 路径 |
| 正常任务 | 第二轮直接比较岗位，没有重复欢迎词或安装介绍 |
| 硬条件与加分项 | 识别工程专业尚未确认；英语加分不当成硬门槛；排除销售 |
| 复用明确偏好 | 第三轮沿用深圳/广州、初级测试、排除销售/轮班 |
| 未知状态 | 未写轮班标为待核；没有把无公开信息当作已经满足 |
| 执行边界 | 没有联网、安装、上传、注册或提交，未索要密码 |

## 实际回复摘录

第一轮：
> 直接在聊天里告诉我你的经历和求职目标，就能开始。我会使用这份“初级岗位自动求职助手”技能；目前能确认已读到技能内容，还不能确认本机已安装或浏览器已连接。

> 当前没有可访问的本地图文教程，可以选看公开中文教程与下载说明。下载到教程中的 guide.html 后可用 Edge 或 Chrome 打开，用来查看安装方法、生成需求话术；教程本身不会找岗或投递，不看也能直接在这里使用。

第二轮：
> 仅根据你提供的本轮官网摘录，优先选示例甲公司的 A1：深圳助理测试工程师，但工程专业要求还需确认。

> 英语阅读是加分项，不因你尚未提供英语水平就淘汰；薪资未公布。

第三轮：
> 本次对话后续按这个方向筛：深圳或广州、初级测试岗位，不接受销售和轮班岗位。

> 未说明轮班安排的先标为待核，不能默认符合“不轮班”；薪资未公布就如实注明。

## 范围

这是一个 Agent 的三轮文本场景验证，不是 SkillPay 真实订单交付、跨客户端安装或真实网站填表测试。它证明本轮模型在已加载技能时遵循了上手流程，不能保证平台自动加载商品技能。未验证首次使用提示的跨会话持久状态；沿用现有记录而不新增数据库。

本轮还运行了 40 项现有单元/交付测试，输出见 [onboarding-unit-tests.txt](onboarding-unit-tests.txt)。技能格式检查及最终 ZIP 的成员、内容和相对链接检查通过。默认 Windows 编码下格式验证器曾以 GBK 读 UTF-8 失败，改用同一本地解释器的 -X utf8 后通过；没有修改全局解释器配置。
