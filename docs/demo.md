# 离线演示

用虚构资料查看岗位筛选、填写检查和中断恢复的行为。无需账号、真实简历或联网，不注册、不上传、不提交申请。

在仓库根目录用已确认的本地 Python 运行：

```text
python tools/demo.py --output evaluation/demo
```

打开生成的 `evaluation/demo/demo.html` 查看演示，`demo.json` 保存机器可读结果。Windows 可使用解释器完整路径，避免触发商店别名。

演示包含 8 个申请包场景和 4 个恢复检查，展示：

- 硬性资格不符时拒绝推进；未写明限制时保留待雇主判断的说明。
- 检查事实冲突、来源时效、附件语言和可选营销条款。
- 验证卡点交接、提交结果未知时阻止重试，以及核对模拟回执后记录状态。

演示调用实际本地检查与状态记录代码，但使用构造的资料和回执。模拟状态中的“已提交”不代表向任何雇主投递；测试范围见[测试记录](../TESTING.md)。
