初级岗位自动求职助手
下载后先看这里

完整解压后，打开能同时看到 SKILL.md、guide.html 和本说明的那一层。把整个技能文件夹安装到你使用的 Agent（例如 Codex、Claude Code），保留全部子目录。
不会安装的话，可以让 Agent 读取本文件夹里的 SKILL.md，按它的提示完成安装。首次加载后，它应当介绍功能、开始方式、三条常用指令和可选教程。
如果 Agent 只说安装完成，可以发这句确认：
“请告诉我你这次实际加载的 entry-level-job-application 的 SKILL.md 路径。读不到就告诉我，不要猜路径。读到了，请按首次使用说明告诉我怎么开始，并指出我能打开的教程。”

一、正常怎么用？
手上有一条官网岗位，即使没有简历也能先核。把链接和两句自己的情况填进这段话：
“使用 entry-level-job-application。这个官网岗位是【链接】。我【毕业届别、专业】，做过【一项相关经历】。请核对实际工作地和硬性资格，引用一条岗位原文，告诉我该继续、先问哪一项，还是跳过。只核岗位，不注册、不上传、不提交。官网读不到时告诉我，我可以贴出职位说明。”

决定准备材料时，可以只在本地写草稿：
“用刚才核过的岗位说明和我提供的经历，仅在本地写草稿，给我检查。不访问招聘表单，不上传附件，不提交。”

如果还没有目标岗位，也可以让 Agent 帮你找：
“使用这个求职技能，读取我的简历，帮我找上海的初级工程师岗位。先搜索，不投递。”

二、guide.html 是什么？
它是可选的使用教程，不是求职软件，也不是投递入口。
用 Edge 或 Chrome 打开后，可以看安装方法、填写示例需求，再复制给 Agent。
会用的客户直接跳过，不需要先填这个网页。

三、文件有什么用？
SKILL.md 和 references、scripts 等文件夹：技能本体，安装时完整保留。
guide.html：可交互的中文教程。
guide.pdf：一页速查，含安装步骤、无简历时的核岗示例和四种申请准备选项。要按自己的选择生成话术，请打开 guide.html。
examples：缺工具时才需要的配置示例，不要覆盖已有配置。

四、记住这两点
真正的搜索、填表和投递由 Agent 执行，网页自己不会操作招聘网站。
准备到最后一步后，Agent 会等你本人提交。如果要它代交，请在核对这份最终申请时明确说“现在替我提交这份申请”。旧代投设置需要在此时重新确认。技能不保证录用，Agent 或模型可能另行收费。
