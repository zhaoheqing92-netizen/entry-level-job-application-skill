初级岗位自动求职助手
下载后先看这里

从 SkillPay 领取或安装后，加载技能的 Agent 应直接介绍功能、开始方式、三条常用指令和可选教程。
如果它只说安装完成，把这句发给它：
“请加载 entry-level-job-application，按其中的首次使用说明告诉我怎么开始，并指出我能访问的教程入口。”

一、正常怎么用？
把技能安装到你正在使用的 Agent（例如 Codex、Claude Code），然后直接告诉它：
“使用这个求职技能，读取我的简历，帮我找上海的初级工程师岗位。先搜索，不投递。”
不会安装的话，可以让 Agent 读取本文件夹里的 SKILL.md，按它的提示完成安装。

二、guide.html 是什么？
它是可选的使用教程，不是求职软件，也不是投递入口。
用 Edge 或 Chrome 打开后，可以看安装方法、填写示例需求，再复制给 Agent。
会用的客户直接跳过，不需要先填这个网页。

三、文件有什么用？
SKILL.md 和 references、scripts 等文件夹：技能本体，安装时完整保留。
guide.html：可交互的中文教程。
guide.pdf：一页速查说明。
examples：缺工具时才需要的配置示例，不要覆盖已有配置。

四、记住这两点
真正的搜索、填表和投递由 Agent 执行，网页自己不会操作招聘网站。
提交申请前要明确授权；这份技能不保证录用，Agent 或模型可能另行收费。

本客户完整包包含技能和教程。请完整解压，不要只取出一个文件。
