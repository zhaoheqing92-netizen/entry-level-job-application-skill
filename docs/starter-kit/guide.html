一页上手
交互版请打开 guide.html：选操作、填方向、复制给 Agent。


1. 完整安装
解压 entry-level-job-application.zip。技能文件夹内直接看见 SKILL.md，并保留全部子目录。Codex 用户级目录为 ~/.agents/skills/；Claude Code 为 ~/.claude/skills/。自定义目录按本机设置。


2. 先只搜索
使用 entry-level-job-application 技能。
根据我的简历，找【城市】的【目标初级岗位】。
最多给我 3 份匹配岗位及官网直达链接。
只搜索，不上传、不投递。缺少信息时集中问我。


3. 确认后再申请
告诉 Agent：允许申请哪些公司和岗位、允许上传什么、最多几份，以及“只填草稿”还是“允许提交”。非必填只写真实优势，只勾选提交必需且适用的条款。


验证码、测评由本人处理；官网确认后才记录成功。需要停下来，直接说“暂停，保存进度”。


缺工具时
先复用已有工具。需要时再看 examples/README.md，按客户端合并配置，不能覆盖原配置。简历和申请记录放在私有文件夹里。

本页是速查单，配置与示例不代表已在所有客户端或招聘网站实测。教程不执行投递，也不包含模型与其他服务费用。
